Guide

  • 원문을 붙여넣으면 자동 파싱됩니다. Ctrl/Cmd+Enter 또는 파싱 버튼으로도 실행합니다.
  • ISRC 1개는 Stereo, 2개는 Stereo / Dolby 순서입니다. 3개 이상은 QC 오류로 표시합니다.
  • 드래그로 셀 범위를 선택합니다. 행 번호·열 이름·좌상단 #으로 행·열·전체를 선택합니다.
  • 표에서 Ctrl/Cmd+C로 TSV 복사, 편집 모드에서 Ctrl/Cmd+V로 붙여넣습니다. 선택이 없으면 전체를 복사합니다.
  • 더블클릭·Enter·F2로 셀 편집, Delete로 선택 값 삭제. 화살표로 이동하고 Shift로 범위를 확장합니다.
  • Ctrl/Cmd+Z 실행 취소, Ctrl/Cmd+Shift+Z 또는 Ctrl/Cmd+Y 다시 실행. 수정하면 QC가 즉시 갱신됩니다.
  • 붙여넣기는 시작 셀부터 적용됩니다. 행은 자동 추가되며, 열 범위를 넘으면 적용하지 않습니다. 헤더 포함 복사는 선택 열의 헤더를 추가합니다.
  • 원문을 다시 파싱하면 편집 결과를 대체합니다. 실행 취소로 복구할 수 있습니다.
  • 외부 라이브러리 없이 단일 HTML로 작동하며, 파일을 새로 열 때마다 빈 상태로 시작합니다.
